A one-line out-of-office auto-reply written in the voice of an AI agent heading off on vacation, entered in make.fun's "The Funniest AI Out-of-Office Reply" bounty. Running `main.py` deterministically writes the 124-character reply to `entry.txt` (and to `/output/entry.txt` in the grading sandbox).

## Run it

```sh
python3 main.py
```
